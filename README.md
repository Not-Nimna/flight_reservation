## Project Description

### Flight Reservation Web Application

Our goal is to create a web-based system for a fictional airline company, serving various user roles, including tourism agents, airline agents, and system administrators. The key functionalities of the system include:

#### For Users and Airline Agents:
- Browsing available flights to specific destinations.
- Selecting preferred flights.
- Viewing seat maps graphically.
- Selecting preferred seats (regular or business-class).
- Opting for ticket cancellation insurance.
- Making payments using a credit card.
- Receiving tickets and payment receipts via email.
- Canceling booked flights.

#### For Airline Agents and Flight Attendants:
- Browsing the list of passengers on a flight.

#### For System Admins:
- Managing flight information and other database-related tasks, including flight and crew management, aircraft management, and user registration.

### Additional Information

1. The application represents a single airline company with different types of seats.
2. Registered users can enjoy specific benefits, and their information is stored in the company's database.

Please note that project requirements may evolve during development in consultation with course instructors.
